# Инструменты поиска

В Docker-образ входят несколько инструментов с разными задачами:

| Инструмент | Когда использовать | Ограничение |
| --- | --- | --- |
| `rg` | точная строка, имя, конфигурационный ключ | не понимает смысл запроса |
| `sg` | AST-паттерны, вызовы, импорты, точные замены | нужен подходящий синтаксический паттерн |
| `semble` | поиск по смыслу в незнакомом репозитории | первый запуск может загрузить локальную модель |
| `ctags` + `jq` | дешёвый индекс символов и фильтрация результата | не строит полный call graph |
| Serena | определения, references, symbol edits | медленнее стартует; включается отдельно |
| Repomix | ограниченная архитектурная карта | полный pack может увеличить контекст |
| Context7 | точная публичная документация библиотек | внешний сервис; не отправлять приватные данные |

Семантические инструменты не должны запускаться все сразу. Сначала выбирается самый дешёвый подходящий метод: точный поиск для известного имени, Semble для intent search, Serena для references и symbol-level изменений.
